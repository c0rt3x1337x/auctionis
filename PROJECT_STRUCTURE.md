# Project Structure

Clean, simple structure for the ZK Sealed-Bid Auction MVP.

```
ZKP/Auction/
│
├── circuits/bid_proof/           # Noir ZK Circuit
│   ├── src/
│   │   └── main.nr              # Circuit implementation (Poseidon hash, bid validation)
│   ├── Nargo.toml               # Circuit configuration
│   ├── Prover.toml              # Example prover inputs
│   ├── README.md                # Circuit documentation
│   └── target/                  # Compiled artifacts (generated by nargo compile)
│       └── bid_proof.json       # Compiled circuit
│
├── contracts/                    # Solidity Smart Contracts
│   ├── SealedBidAuction.sol     # Main auction contract
│   ├── UltraVerifier.sol        # ZK verifier (generated by nargo codegen-verifier)
│   └── interfaces/
│       ├── ISealedBidAuction.sol    # Auction interface
│       └── IUltraVerifier.sol       # Verifier interface
│
├── frontend-simple/              # Simple HTML/JS Frontend
│   ├── index.html               # Main UI page
│   ├── app.js                   # Application logic & wallet integration
│   ├── noir-integration.js      # ZK proof generation using Noir.js
│   ├── styles.css               # Styling
│   ├── vite.config.js           # Vite configuration
│   ├── package.json             # Frontend dependencies
│   └── circuit/                 # Circuit artifacts (copied from circuits/bid_proof/target/)
│       └── bid_proof.json       # Circuit for browser proof generation
│
├── scripts/                      # Deployment Scripts
│   ├── deploy-simple.js         # Deploy contracts to network
│   └── start-auction.js         # Start the auction
│
├── test/                         # Contract Tests
│   ├── Auction.test.ts          # Basic auction tests
│   ├── SealedBidAuction.test.ts # Full auction tests
│   └── FullIntegration.test.ts  # End-to-end integration tests
│
├── deployments/                  # Deployment Info (generated)
│   └── localhost.json           # Contract addresses for local network
│
├── compile-circuit.sh           # Script to compile circuit in WSL
├── setup-wsl.sh                 # Script to setup WSL environment
│
├── hardhat.config.ts            # Hardhat configuration
├── package.json                 # Root dependencies
├── tsconfig.json                # TypeScript config (for contracts/tests)
│
├── README.md                    # Main project documentation
├── SETUP.md                     # Detailed setup guide
├── QUICKSTART.md                # Quick reference guide
└── TODO-CHECKLIST.md            # Step-by-step completion checklist
```

## File Purposes

### Circuit Files (`circuits/bid_proof/`)
- **main.nr**: Noir circuit that proves bid validity using Poseidon hash
- **Nargo.toml**: Circuit project configuration
- **target/bid_proof.json**: Compiled circuit (generated, needed by frontend)

### Contract Files (`contracts/`)
- **SealedBidAuction.sol**: Main auction logic with 3 phases (COMMIT, REVEAL, FINALIZED)
- **UltraVerifier.sol**: Verifier contract generated from Noir circuit
- **interfaces/**: Contract interfaces for clean architecture

### Frontend Files (`frontend-simple/`)
- **index.html**: Single-page application UI
- **app.js**: Wallet connection, contract interaction, UI logic
- **noir-integration.js**: ZK proof generation using @noir-lang/noir_js
- **styles.css**: Simple, clean styling

### Script Files (`scripts/`)
- **deploy-simple.js**: Deploys both verifier and auction contracts
- **start-auction.js**: Starts the auction (changes phase to COMMIT)

### Test Files (`test/`)
- Contract tests using Hardhat and Chai
- Integration tests for full auction flow

### Build Scripts
- **compile-circuit.sh**: Compiles circuit, generates verifier, copies artifacts
- **setup-wsl.sh**: Installs Noir and Node.js in WSL

### Documentation
- **README.md**: Overview and quick start
- **SETUP.md**: Detailed setup instructions with troubleshooting
- **QUICKSTART.md**: Minimal quick reference
- **TODO-CHECKLIST.md**: Step-by-step completion guide

## Key Dependencies

### Root (`package.json`)
- hardhat, ethers, @noir-lang packages
- OpenZeppelin contracts
- Testing tools (chai, mocha)

### Frontend (`frontend-simple/package.json`)
- ethers.js (wallet & contract interaction)
- @noir-lang/noir_js (proof generation)
- @noir-lang/backend_barretenberg (proving backend)
- vite (dev server)

## Generated Files (Not in Git)

These are created during setup/compilation:
- `circuits/bid_proof/target/`
- `contracts/UltraVerifier.sol`
- `frontend-simple/circuit/bid_proof.json`
- `deployments/*.json`
- `node_modules/`
- `cache/`, `artifacts/`

## Workflow

1. **Circuit Development**: Edit `circuits/bid_proof/src/main.nr`
2. **Compile**: Run `./compile-circuit.sh`
3. **Deploy**: Run `scripts/deploy-simple.js`
4. **Frontend**: Update addresses, run `npm run dev`
5. **Test**: Use the UI to commit/reveal bids

## Clean Architecture

- Smart contracts are independent of frontend
- Noir circuit is standalone and testable
- Frontend is simple JavaScript (no complex build)
- All configuration in clear, editable files
